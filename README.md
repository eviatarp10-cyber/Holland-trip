# 🌷 הטיול שלנו להולנד

אתר קטן ומהיר שמציג את הלוז היומי של הטיול. ללא שרת, ללא מסד נתונים, ללא תהליך בנייה —
שלושה קבצים סטטיים שמתארחים ב-Vercel בחינם.

## איך עורכים את התוכנית

כל התוכן נמצא בקובץ אחד: [`public/itinerary.js`](public/itinerary.js).
עורכים אותו, שומרים, וה-push ל-`main` מתפרסם אוטומטית תוך שניות.

מבנה של יום:

```js
{
  date: "2026-07-01",          // חובה, בפורמט YYYY-MM-DD
  title: "נחיתה באמסטרדם",      // כותרת היום
  city: "אמסטרדם",              // אופציונלי
  stay: "שם המלון",             // אופציונלי
  summary: "משפט על היום",      // אופציונלי
  items: [
    {
      time: "09:00",                        // אופציונלי
      type: "sight",                        // אופציונלי, קובע את האייקון
      title: "מוזיאון ואן גוך",
      note: "כרטיסים מראש",                 // אופציונלי
      link: "https://maps.google.com/...",  // אופציונלי
      linkText: "מפה"                       // אופציונלי
    }
  ]
}
```

ערכים אפשריים ל-`type`:
`flight` ✈️ · `train` 🚆 · `car` 🚗 · `bike` 🚲 · `walk` 🚶 · `boat` ⛵ · `hotel` 🏨 ·
`food` 🍽️ · `sight` 🏛️ · `nature` 🌷 · `shop` 🛍️ · `kids` 🎡 · `note` 📝

### מגירת פרטים לאטרקציה

פעילות שיש לה אחד מהשדות הבאים נהיית לחיצה ופותחת מגירה מלמטה:

```js
{
  time: "09:00", type: "sight", title: "מוזיאון ואן גוך",
  highlight: true,                          // אטרקציה עיקרית – מודגשת
  place: "Van Gogh Museum, Amsterdam",      // יוצר כפתור ניווט ב-Google Maps
  details: ["פסקה ראשונה", "פסקה שנייה"],   // או מחרוזת אחת
  info: { hours: "09:00–18:00", price: "€24", duration: "כשעתיים" },
  tips: ["להגיע 10 דקות לפני", "יש לוקרים בכניסה"],
  links: [{ label: "אתר רשמי", url: "https://..." }]
}
```

מפתחות אפשריים ל-`info`: `hours` `price` `duration` `address` `booking` `transport` `phone`.

### עמוד "מידע כללי"

`TRIP.info` הוא מערך של סעיפים (טיסות, לינה, חירום...). כל סעיף: `{ type, title, text?, items: [{ label, value?, url?, linkText?, place? }] }`.

## מה האתר עושה

- נפתח אוטומטית ביום הנוכחי של הטיול (ולפני הטיול — ביום הראשון)
- רצועת ימים לגלילה מהירה, עם סימון של היום הנוכחי
- ציר זמן לכל יום עם שעות, אייקונים, הערות וקישורים
- לחיצה על אטרקציה פותחת מגירת פרטים: תיאור, שעות/מחיר/משך, טיפים, קישורים וניווט
- במהלך הטיול, הפעילות הנוכחית ביום מסומנת "עכשיו"
- עמוד "מידע כללי" לטיסות, לינה ופרטים שימושיים
- כפתור לתצוגת כל הימים ברצף
- ניתן להוסיף למסך הבית בטלפון כאפליקציה (PWA manifest + אייקונים)
- מותאם למובייל, תומך במצב כהה, עברית RTL

## הרצה מקומית

```bash
python3 -m http.server 8000 --directory public
```

ואז לפתוח <http://localhost:8000>.

## פריסה ל-Vercel

1. להיכנס ל-<https://vercel.com/new>
2. לבחור **Import** על הריפו `Holland-trip`
3. להשאיר את כל ההגדרות כברירת מחדל וללחוץ **Deploy**

מאותו רגע, כל push ל-`main` מתעדכן באתר תוך כדקה.
